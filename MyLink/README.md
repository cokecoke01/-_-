## 🚀 프로젝트 주요 기능

1. **상단 헤더 & 반응형 UI**
   - `MyLink` 시그니처 로고 및 홈 이동
   - `내 페이지` 실시간 CTA 버튼 (방문자 시점 미리보기 전환)
   - 우측 상단 프로필 클릭 시 나타나는 드롭다운 메뉴 (레퍼런스 2 완벽 구현)
     - 👁️ 내 페이지 미리보기
     - 📋 링크 복사 (클립보드 복사 및 토스트 알림)
     - 📊 통계 확인하기 (실시간 데이터베이스 기반 대시보드)
     - ⚙️ 프로필 설정 (이름, ID, 자기소개, 프로필 이미지 변경)
     - 🚪 관리자 로그아웃 / 로그인 세션 전환

2. **개인 브랜딩 프로필 (김동영 기획자)**
   - **이름**: 김동영
   - **아이디**: `@dongyoung`
   - **자기소개**: 사람의 심리를 읽고, 브랜드의 이야기를 기획하는 광고·마케팅 기획자
   - **핵심 슬로건**: "사람을 관찰하고, 마음을 읽고, 브랜드의 이야기를 기획합니다."
   - **관리자 프로필 이미지 변경 기능**: 레퍼런스 고양이 캐릭터 및 다양한 프리셋 지원

3. **링크 관리 (CRUD & 정렬)**
   - `+ 새로운 링크 추가하기` 메인 파란색 CTA 버튼
   - 각 플랫폼별 전용 아이콘 (GitHub, Google, 블로그, 포트폴리오, 인스타그램 등)
   - 개별 링크 실시간 조회수 (`👁 조회수`)
   - 링크 수정 모달 (제목, URL, 아이콘, 부가설명)
   - 링크 삭제 모달 (확인 절차 제공)
   - 링크 순서 변경 (위/아래 이동)

4. **실시간 누적 조회수 및 통계 분석 (Database)**
   - **전체 페이지 방문 수**: 세션 기준 중복 방지 방문자 수 누적
   - **개별 링크 조회수**: 카드 클릭 시 실시간 데이터베이스에 +1 저장 후 안전하게 외부 URL 이동
   - **통계 대시보드**:
     - 전체 방문 수, 총 클릭 수, 전환율(CTR), 최다 클릭 링크
     - 최근 7일간 일별 방문 및 클릭 추이 비교 차트
     - 개별 링크별 클릭 수 및 클릭 점유율 프로그레스 바

## 💻 로컬 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 풀스택 개발 서버 실행 (포트 3000)
npm run dev

# 3. 브라우저에서 http://localhost:3000 접속
```

## 🌐 Vercel 배포 가이드

1. GitHub 저장소에 `MyLink` 폴더를 푸시합니다.
2. [Vercel](https://vercel.com) 로그인 후 `Add New Project` 선택
3. 저장소를 불러온 뒤, **Root Directory**를 `MyLink`로 지정하거나 기본값으로 설정 후 `Deploy` 버튼을 클릭합니다.
4. 배포 완료 후 발급되는 `https://*.vercel.app` URL을 과제 제출란에 작성합니다.
